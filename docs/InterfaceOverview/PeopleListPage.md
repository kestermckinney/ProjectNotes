# People List Page

## Managing Your List Of People

Project Notes keeps a list of people that can be associated with projects. Native [contact synchronization](Preferences.md#contact-synchronization) imports from Outlook (classic), Microsoft 365, Thunderbird, or iCloud according to your integration choice. You can select source address books and review uncertain person or client matches. Project Notes may have a customization that imports and exports names from other enterprise applications such as an accounting system or customer relationship manager. Native matching uses saved source identities and asks you to review uncertain matches before creating a person.

## The People List Page Layout

To navigate to the People List Page, click the **People** icon in the icon rail. The view of people can be filtered using the [Filter Tool](<FilterTool.md>), or narrowed with the quick-search box above the list.

**To create a new person:**

1. Click **+ New** in the bar above the list, or choose **New Record** from the app menu (the menu icon at the top of the icon rail).
2. Type in the **Name**. **Name** is a required field.
3. Type in the **Email**, **Office Phone**, **Cell Phone** if available. A person without an **Email** cannot be picked as a report recipient or a meeting attendee.
4. Type in the **Role**. **Role** will be copied to the project team member role by default when a person is added to a project.
5. Select the **Client** from the drop down.



**To delete a person:**

1. Right-click the person's card (or click its **⋮** button) to open its menu.
2. Choose **Delete**.
3. Click **Yes** to confirm the deletion. Note: You may not be able to delete people if they are associated with other project information. In this case, clicking **Yes** opens the Search Page — see [Search Page](<SearchPage.md>) for how to work with search results.

**To navigate to a person's client:**

1. Right-click the person's card (or click its **⋮** button) to open its menu.
2. If the person has a **Client** assigned, choose **Go To Client** from the menu.
3. The application will automatically switch to the Clients page and open that client's record.

**To edit a person:**

1. Click the person's card to open it.
2. Type in or select the new value in any field — changes save automatically.
3. On the person detail page, click the **⋮** button in the top-right to access additional actions:
   - **Export XML** — Export the person's record
   - **Go To Client** — Navigate to the person's assigned client (if assigned)
   - **Refresh** — Reload the person's data from the database
   - **Plugins** — Any plugin actions configured for people records
