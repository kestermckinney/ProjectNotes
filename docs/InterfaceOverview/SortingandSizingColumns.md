# Sorting and Sizing Columns

The Projects, Items, People, and Clients lists display records as cards rather than a resizable, sortable spreadsheet-style grid. There are no column widths to drag and no column header to click for sorting — each list is shown in a fixed order.

To narrow down a long list, use the quick-search box in the bar above the list, or open the [Filter Tool](<FilterTool.md>) to match specific field values, search text, or a date range.
