# Team Member Quick Add

**Team Member Quick Add** puts a new person on a project's team without a trip to the Contacts list first.

## Adding a team member

1. Open the project and go to its **Team** tab.
2. Right-click any team member and choose **Team Member Quick Add**.
3. Enter the person's details:

| Field | Description |
| :--- | :--- |
| **Name** | Full name. Required. |
| **Email** | Email address. |
| **Office phone**, **Mobile phone** | Optional. |
| **Company** | Pick an existing company, or type a new one under **Or a new company**. |
| **Role** | The person's role on this project. |

4. Choose **Add**.

The contact, a new company if you typed one, and the team row are saved together, so a problem with one leaves none of them half-added. The person appears on the **Team** tab and in the Contacts list right away.

If a contact with that name already exists, it is updated with what you entered rather than duplicated.
